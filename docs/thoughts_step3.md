# 내 생각 저장소

- Qualifier가 무엇이냐?
  - 여러 개의 인터페이스의 구현체가 존재하더라도, 내가 필요로 하는 구현체를 사용할 수 있도록 하는 것.
- 현재 나는 한 인터페이스에서 하나의 구현체만 사용할 수 있도록 되어 있다.
  - 그러면 어떻게 구현하지? instanceMap의 value가 리스트이면서, 그 중 내가 사용하고 싶은 구현체를 찾아서 적용시킨다?
  - 그러려먼 사용할 구현체를 만드는 무언가에 마커를 찍어야 한다.
    - 예를 들면 DefaultCartRepository를 사용할거야. @DefaultCart를 만들어서 사용되는 곳에 붙이고, 
    - @DefaultCart가 있는 파라미터라면, 이 녀석의 생성하는 로직을 갖고 있는다?
  - 그러면 DiManager에서 생성하기 위해서는 @DefaultCart라는 애노테이션이 있음을 알고 있어야하고, 결국 app -> di로 되는게 아닌가?
  - 기똥찬 방향을 제시해줬다.
    - Class타입과 애노테이션 타입을 갖는 Data class 객체를 만들어 Key로 사용하는 것이다. 그러면 value가 복잡해지지 않을 수 있다.
